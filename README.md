# Spacy

Orbital threshold wallet for ETHPrague 2026.

> Sign in with Google. Transactions signed across heterogeneous TEEs from
> ground to orbit. Verifiable cosmic entropy. Open-source under AGPL-3.0.

## Local development

```bash
bun install
bun run dev
```

This starts every app in `apps/*` in parallel via Turborepo.

## Workspaces

- `apps/web` — Vite + React frontend
- `apps/api` — Backend service (placeholder until SpaceComputer KMS lands)
- `packages/types` — Shared TypeScript types
- `packages/utils` — Shared utilities
